# 🛍️ Digital Store - Projeto Front-end

Projeto e-commerce desenvolvido em React como avaliação final de Front-end da Digital College [13, 15].

## 🚀 Tecnologias
- **React** (Vite) [15]
- **React Router DOM** (Gerenciamento de rotas e navegação)
- **PrimeReact** (Biblioteca de componentes de interface)
- **PrimeFlex** (Sistema de Grid e utilitários CSS) [14]
- **PrimeIcons** (Pacote de ícones da aplicação)
- **Styled-components** (Estilização modular via CSS-in-JS)

## ⚙️ Como rodar o projeto
```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev

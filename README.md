# 🛍️ Digital Store - Projeto Front-end

Aplicação e-commerce desenvolvida em React para a loja **Digital Store**, como projeto final do curso de Front-end da Digital College.

---

## 📌 Progresso do Projeto

- [x] **Dia 21:** Inicialização do projeto React (Vite), estrutura de pastas e integração com Git/GitHub.
- [x] **Dia 22:** Design System, paleta de cores globais (`index.css`) e integração de bibliotecas UI.
- [x] **Dia 23:** Componente `<Logo />` em SVG Inline dinâmico (suporte a variantes `default` e `white`).
- [x] **Dia 24:** Estrutura base de rotas com React Router DOM e componente `<Layout />`.
- [x] **Dia 25:** Componente `<Header />` completo com busca, navegação ativa e área de usuário.
- [x] **Dia 27:** Componente `<Footer />` responsivo com logo branca e direitos autorais.
